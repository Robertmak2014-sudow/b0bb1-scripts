## Scripts

### `БПЛА.lua` — drone combat suite

Full-featured combat assist for drone-based games.

**Aimbot**
- Hard lock / smooth aim (toggleable)
- Pixel-perfect FOV (matches the on-screen circle)
- Prediction for moving targets
- Target priority: `closest` / `farthest` / `weakest`
- Auto-fire
- Ignore own drones
- Ignore dead drones

**Visuals**
- ESP box with customizable color scheme
- Drone name labels
- HP bar (color-graded: green → red)
- Distance readout
- FOV circle overlay

**Interface**
- Draggable UI panel with spring animations
- 6 color themes (purple, cyan, red, green, pink, orange)
- Hotkeys:
  - `F` — aimbot on/off
  - `G` — ESP on/off
  - `RightShift` — panel open/close
- Event log (drone spawns/despawns)
- FPS counter
- Target counter

**Utilities**
- Respawn all drones
- Clear event log
- Safe unload with confirmation dialog

## Usage

1. Load `БПЛА.lua` in any Roblox executor.
2. Enter your access key when prompted.
3. Use the UI panel to configure.

**Requirements:**
- A Roblox executor with `game:HttpGet` support
- Internet access (for key authentication)
- `VirtualInputManager` support (for auto-fire)
